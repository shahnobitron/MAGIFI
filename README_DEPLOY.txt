MAGIFI WEB DEPLOY
=================

1. Export the Godot project using the "MAGIFI Web" preset.
2. Godot will produce a Web export containing the HTML/WASM/PCK files.
3. Create:
       WEB_DEPLOY/
         index.html
         game/
           MAGIFI.html
           MAGIFI.wasm
           MAGIFI.pck
           ...other generated web files...
4. Upload the contents of WEB_DEPLOY to your static web host.
5. Point your domain (for example magifi.com) at that host.

IMPORTANT:
- The domain itself must be purchased/registered separately.
- This package prepares the project and web shell; the actual WASM/PCK
  must be generated by Godot's Web exporter.
- After deployment, visitors do NOT need Godot installed.

For updates:
- Change the Godot project.
- Re-export the Web preset.
- Replace WEB_DEPLOY/game/ with the new exported files.
- Upload the updated site.

The current game uses user:// for MAGIFI ID/profile storage. On Web,
Godot maps user:// to browser-local IndexedDB storage, so the profile
persists per browser/device rather than becoming a server account.
